# Excel-Assignment2-Data-Cleaning-and-Transformation
# Overview
This Assignment demonstrates the process of cleaning and transforming a product dataset using Microsoft Excel. It focuses on improving data quality, consistency and readability through various data cleaning techniques.
# Task Performed
1. Handling Missing Values
  * Identified missing values in the Price column using COUNTBLANK function.
  * Checked for missing categories and handled them appropriately.
2. Correcting Inconsistent Data
  * Identified inconsistent text formats in the Product Name column.
  * Checked and corrected spelling mistakes and inconsistencies in the Category column.
  * Used Find and Replace to standardize text values.
3. Removing Duplicates
  * Identified duplicate records based on the entire row.
  * Removed duplicate rows to maintain data accuracy.
4. Splitting and Merging Data
  * Split the Product ID column into Manufacturing Date and Country Code.
  * Combined Brand Name and Product Name into a new Product Brand column.
5. Number Formatting
  * Formatted the Price column as Currency.
  * Changed the Mnaufacturing Date column to the DD-MM-YYYY format.
 6. conditional Formatting
    * Applied Data Bars to the Price column.
    * Highlighted cells belonging to the Electronics category using conditional formatting.

  * Find and Replace
  * Remove Duplicates
  * Text to Columns
